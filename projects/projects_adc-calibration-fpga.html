FPGA Prototyping

SAR ADC Calibration using FPGA

Designed and implemented a hardware cache controller in RTL to efficiently manage data transfers between the processor and main memory. The project focuses on reducing memory access latency through cache management and control logic.

Year :

2025

Industry :

Mixed Signal System

Project Duration :

6 Months

Objective :

Develop an FPGA-based signal acquisition and processing system using the onboard XADC of the Zybo Z7-10. The objective was to acquire analog signals reliably, improve ADC calibration through optimization algorithms, and perform FFT-based frequency-domain analysis

Architecture :

  • Used the Zybo Z7-10 onboard XADC to digitize incoming analog signals.

  • Processed the acquired samples using FFT to obtain the frequency-domain representation of the input signal.

  • Implemented a calibration approach using Particle Swarm Optimization (PSO) to optimize ADC calibration parameters and improve measurement accuracy.

  • Further refined the optimized parameters using the Nelder–Mead optimization algorithm to improve convergence and calibration results.

  • Integrated the acquisition, calibration, optimization and signal-processing stages within the FPGA development workflow.

Challenge :

  • Achieving stable and reliable analog signal acquisition through the XADC.

  • Handling ADC calibration parameters and selecting suitable optimization strategies.

  • Balancing PSO exploration with Nelder–Mead local refinement to obtain better calibration parameters.

  • Integrating calibrated sample data with the FFT processing pipeline.

Summary :

Developed an FPGA-based analog signal acquisition and FFT analysis system, incorporating a hybrid optimization approach using PSO and Nelder–Mead for ADC calibration refinement. The project provided practical experience in FPGA-based data acquisition, numerical optimization, ADC calibration and digital signal processing.
