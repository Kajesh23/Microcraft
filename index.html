I'm an aspiring Digital System Design Engineer

WHAT I CAN DO FOR YOU

I design and validate dependable digital hardware—from RTL and timing analysis to FPGA-based systems—turning complex communication and signal-processing ideas into implementation-ready solutions.

1. RTL Design

Synthesizable Verilog and SystemVerilog RTL development

Generate gate-level netlists using synthesis tools

Implement low-power techniques like clock gating, power gating, and signal isolation

Run syntax and quality checks using linting tools

2. Design Verification

Testbench creation, simulation, and debug workflows

Assertion-aware verification and coverage-driven thinking

3. FPGA System Design

Xilinx ZedBoard and Zybo Z7010 development

MicroBlaze-based embedded and Ethernet-connected systems

High-speed communication and signal-processing pipelines

Hardware–software integration and on-board validation

4. Static Timing Analysis

Develop, validate, and manage Synopsys Design Constraints (SDC)

Run setup, hold, recovery, removal, clock-gating, and asynchronous path analysis

Build custom Tcl, Perl, or Python scripts to automate report parsing

Interaction design and micro-animations
